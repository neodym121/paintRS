# Поведение оригинала — заметки clean-room исследования

Единственный источник — **наблюдаемое поведение** установленного Microsoft Paint через снимки окна
и ввод мышью/клавиатурой. Исполняемые файлы, ресурсы и память программы не исследовались.
Тексты интерфейса оригинала здесь пересказаны своими словами; английские названия пунктов
приведены только как идентификаторы для сверки.

## Условия
- Paint **11.2605.81.0**, Windows 11 IoT Enterprise LTSC 2024 (26100), экран 1920×1080, 100% (96 DPI),
  тёмная тема, английский интерфейс. Исследование: 16.10.2026.
- Ввод: Computer use (клики, клавиши, удержание модификаторов) + SendInput для протяжек мышью.
- Снимки: захват только окна Paint (PrintWindow) — 1 пиксель экрана = 1 пиксель холста при 100%.

| `brushes.md` | 9 кистей, эталон, механика накопления |
| `shapes.md` | 23 фигуры, контур/заливка/толщина, черновая фигура, Shift |
| `selection.md` | выделение, меню, перемещение, контекстное меню холста |
| `text.md` | текстовая рамка и панель форматирования |
| `colors.md` | цвета 1/2, палитра, диалог Edit colors |
| `layers.md` | модель документа (фон + слои), панель слоёв |
| `image-menu.md` | обрезка, поворот, отражение, изменение размера, ручки холста |
| `file-menu.md` | меню File/Edit, новый документ, сохранение, форматы |
| `view.md` | масштаб, линейки, сетка, отображение |
| `shortcuts.md` | горячие клавиши (проверенные и из меню) |
| `dialogs.md` | состав и порядок кнопок диалогов, страница настроек |
| `statusbar.md` | строка состояния |
| `DIFFS.md` | расхождения PaintRS с оригиналом |
| `img/` | эталоны (`ref-*` — наши тестовые рисунки, отрендеренные оригиналом) и локальные снимки интерфейса (`ui-*`) |
