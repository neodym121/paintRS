# Группа Image (обрезка, размер, поворот, отражение)

Раскладка группы: `[Crop] [Rotate ▾]` / `[Remove background (ИИ)] [Flip ▾]` + крупная кнопка
`[Resize and skew]` справа.

## Crop (обрезка)
- Активна только при наличии выделения; горячая клавиша **Ctrl+Shift+X** (из контекстного меню).
- Холст обрезается до габарита выделения (проверить на этапе 5/7, в т.ч. с лассо).

## Rotate ▾
- Rotate right 90° · Rotate left 90° · Rotate 180° · **Rotate custom** (произвольный угол).
- Rotate custom: маленький диалог с одним полем угла («0°») + OK/Cancel.
  Положительный угол — **по часовой стрелке**. Холст **расширяется до габарита** повёрнутого
  изображения (400×300 на 30° → 496×460 = 400·cos30+300·sin30 × 400·sin30+300·cos30),
  новые углы — прозрачные (виден фон).
- Без выделения — поворачивает всё изображение (все слои?); с выделением — выделение (проверить).

## Flip ▾
- Flip vertical · Flip horizontal.

## Resize and skew (Ctrl+W)
Диалог (`dialogs.md`):
- Resize: **Percentage / Pixels** (радио), поля Horizontal / Vertical, между ними кнопка-переключатель
  **«Maintain aspect ratio»** (по умолчанию включена). В режиме Pixels — текущий размер изображения
  (или выделения). 400 → 200 по горизонтали автоматически даёт 300 → 150.
- Skew: Horizontal / Vertical в градусах («0°»).
- OK / Cancel.
- Ресемплинг — **сглаживающий** в обе стороны: уменьшение 50% бинарного аэрографа даёт
  произвольные промежуточные тона (не только кратные 64 → фильтр шире 2×2, похоже на
  бикубический/«high quality»), увеличение ×3 даёт мягкие края 1–2 px. В PaintRS: уменьшение —
  Lanczos3 (fast_image_resize), увеличение — бикубический/билинейный; уточнить сравнением на этапе 7.
- Изменение размера/поворот — одна запись истории.

## Ручки холста
- 8 ручек (углы + середины сторон). Тянуть можно за любую: холст меняет размер с этой стороны,
  содержимое привязано к противоположной стороне (проверено: правый нижний угол — расширение вправо/вниз;
  левый верхний внутрь — обрезка слева/сверху, содержимое сместилось).
- Новая область — прозрачная (виден фон). Холст после отпускания перецентрируется.

## Invert color (Ctrl+Shift+I)
Есть в контекстном меню холста — инвертирует цвета выделения/изображения (проверить на этапе 7).
