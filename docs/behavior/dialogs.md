# Диалоги

Тексты — только смысл (не дословно). Порядок кнопок — как в оригинале: основная кнопка слева.

## Image properties (Ctrl+E) — `img/ui-dialog-image-properties.png`
- Заголовок «свойства изображения». Размер ≈546×630.
- Блок «атрибуты файла»: дата последнего сохранения, размер на диске (или «недоступно»), разрешение (96 DPI).
- Блок «единицы»: дюймы / сантиметры / пиксели (радио, по умолчанию пиксели).
- Блок «размер изображения»: ширина, высота, кнопка «по умолчанию» (1152×648 на экране 1920×1080).
  В дюймах значения с 3 знаками (400 px → 4.170), в см — с 2 (10.58).
- Кнопки: **OK** · **Cancel**.
- Пункта «цветное / чёрно-белое» в этой версии **нет**. Сохранения пропорций нет.
- Изменение размера здесь обрезает/дополняет холст (не масштабирует).

## Resize and skew (Ctrl+W)
- Блок «изменить размер»: проценты / пиксели (радио); поля «по горизонтали», «по вертикали»,
  между ними кнопка-переключатель «сохранять пропорции» (вкл. по умолчанию, подсказка при наведении).
- Блок «наклон»: по горизонтали / по вертикали в градусах.
- Кнопки: **OK** · **Cancel**.

## Rotate custom
- Одно поле угла с суффиксом «°», кнопка очистки поля; **OK** · **Cancel**.

## Edit colors / Background color — `img/ui-dialog-edit-colors.png`
- См. `colors.md`. Размер ≈700×650. Кнопки **OK** · **Cancel**.

## Вопрос о сохранении
- «Сохранить работу?» + «есть несохранённые изменения в …».
- **Save** (основная) · **Don't save** · **Cancel**. Компактный, по центру над холстом.

## Сохранение сведённого изображения
- «Сохранить как сведённое изображение?» + «слои нельзя будет редактировать; проект позволит».
- **Save as project file** (основная) · **Continue** · **Cancel**.

## Системные
- Открыть / Сохранить как — стандартные диалоги Windows (в PaintRS — `rfd`, тоже нативные).
- Ошибка неверного имени — от системного диалога.

## Информационная плашка (не модальная)
- Жёлтая плашка над холстом при скрытом активном слое: иконка, заголовок «слой скрыт», пояснение,
  кнопка «Показать слой».

## Настройки (страница, не диалог)
- Открывается шестерёнкой справа в строке меню; заменяет весь редактор, сверху стрелка «назад».
- Appearance → App theme: Light / Dark / Use system setting (радио).
- Блок про ИИ-водяной знак — не переносим.
- Справа «О программе»: версия, ссылки на лицензию/конфиденциальность/сторонние компоненты, «Отзыв».
- В PaintRS: тема (светлая/тёмная/системная), язык (RU/EN), сглаживание (авто/всегда/никогда),
  горячие клавиши, «О программе» + THIRD_PARTY.
