# Вид и масштаб

## Меню View
- Zoom ▸: 100% (**Ctrl+0**) · Zoom in (**Ctrl+PageUp**) · Zoom out (**Ctrl+PageDown**) · Fit to window
  (клавишу уточнить; в строке состояния — отдельная кнопка).
- —
- Rulers (**Ctrl+R**) · Gridlines (**Ctrl+G**) · ✓ Status bar
- —
- ✓ Always show toolbar · Automatically hide toolbar (лента сворачивается/всплывает)
- —
- Full screen (**F11**) · Thumbnail (окно-миниатюра; не удалось открыть в эксперименте — проверить)

## Масштаб
- Диапазон **10% … 1000%**.
- Пресеты выпадающего списка (сверху вниз): 1000, 900, 800, 700, 600, 500, 400, 300, 200, 100,
  75, 50, 25, 12.5%. Поле редактируемое — можно ввести своё значение.
- Шаг Ctrl+PageUp/PageDown, кнопок «−/+» и лупы:
  | Текущий масштаб | Шаг |
  |---|---|
  | < 200% | ±10% |
  | 200 … < 600% | ±25% |
  | ≥ 600% | ±50% |
  (Проверено: 100→150 за 5 шагов, 200→325 за 5, 500→525→550, 100→800 за 30, 1000→950 кнопкой «−».)
- Fit to window: вписывает с полями (400×300 → 235.5%) — масштаб может быть дробным.
- При 1000% пиксели рисуются **без сглаживания** (чёткие квадраты), сетки пикселей нет
  (только Gridlines по Ctrl+G).
- Ctrl+колесо, колесо, Shift+колесо — проверить (ожидаемо: масштаб / вертикальная / горизонтальная прокрутка).

## Линейки (Ctrl+R)
- Сверху и слева, толщина ≈20 px, тёмный фон, мелкие деления каждые 10 px холста, длинные с подписью
  каждые 100 px (при 100%). Начало (0) — у левого/верхнего края холста.

## Сетка (Ctrl+G)
- Пунктирные серые линии каждые **10 px холста** (при 100%), поверх изображения.
- Поведение при других масштабах — проверить.

## Отображение холста
- Прозрачность — шахматка 8×8 px экрана (#A8A8A8 / #969696).
- Сглаживание при уменьшении — проверить на этапе 1 (сравнить 25% и 12.5%).

## В PaintRS дополнительно (по ТЗ)
- Режим сглаживания: авто (линейная + мипмапы при уменьшении, nearest и сетка пикселей от 800%) /
  всегда / никогда. В оригинале сетки пикселей нет — помечено в DIFFS как расширение.
