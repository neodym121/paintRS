# Расхождения PaintRS с оригиналом

Сюда заносятся все расхождения: найденные при сверке после каждого этапа (статус «исправить») и
осознанные (статус «намеренно» + причина). Формат: область — что в оригинале — что у нас — статус.

## Намеренные (решения ТЗ)
| Область | Оригинал | PaintRS | Причина |
|---|---|---|---|
| ИИ | Copilot, Remove background, Generative erase, ИИ-стирание ластиком, плавающая ИИ-панель у выделения, водяной знак ИИ | нет | ТЗ: никаких ИИ-функций |
| Строка меню | Share, Feedback | нет | системный «поделиться» и отзыв в Microsoft — вне рамок |
| File | Set as desktop background, Import from scanner or camera | нет | вне рамок ТЗ |
| Заголовок | без отметки несохранённых изменений | «*» перед именем при несохранённых изменениях | прямое требование ТЗ |
| Оформление | цвета/иконки/шрифт Windows 11 | своя палитра, Lucide, IBM Plex Sans | ТЗ, раздел 10 |
| Палитра цветов | 20 стандартных цветов оригинала | свой набор с той же логикой рядов | clean-room, ТЗ |
| Диалог «Изменить цвета» | 48 основных цветов оригинала | свои 48 (10 тонов × 4 + 2 нейтральные колонки) | clean-room |
| Ползунок ластика | под ползунком кнопка ИИ-стирания, дорожка короче | кнопки нет, панель как у заливки | ИИ исключён |
| Слои | нет непрозрачности/режимов слоя в UI | непрозрачность слоя (и режим Normal) | ТЗ, раздел 3 и 4 |
| Отображение | сглаживание/шахматка по своим правилам, сетки пикселей нет | авто/всегда/никогда, nearest + сетка пикселей от 800% | ТЗ, принцип 5 |
| Лента, группа Image | слот «Remove background» (ИИ) | в этом слоте «Инвертировать цвета» (есть в контекстном меню оригинала, Ctrl+Shift+I) | ИИ исключён, слот не пустует |
| Лента | группа Copilot между Colors и Layers | нет; Layers сдвинута на её место | ТЗ: без ИИ |
| Масштаб 100% | — (не проверено на DPI > 100%) | 100% = 1 пиксель изображения на 1 физический пиксель экрана при любом DPI | чёткость без пересэмплинга; проверить на оригинале при 125/150% |
| Палитра цветов, иконка «Изменить цвета» | радужный круг | кнопка с иконкой палитры (без градиента) | ТЗ: без градиентов |
| Формат проекта | `.paint` (закрытый формат) | свой открытый формат проекта (`.paintrs`, zip: манифест + PNG-слои) | clean-room |

## Решения автора ТЗ (приняты 16.10.2026, делаем как в колонке «Решение»)
| Область | Оригинал | ТЗ | Решение |
|---|---|---|---|
| Сглаживание фигур | фигуры **без сглаживания** (только чистые цвета) | «все фигуры — с антиалиасингом» | по умолчанию как в оригинале (без AA), переключатель «Сглаживать фигуры» в настройках |
| Ctrl+Shift+S | «Сохранить как проект» | «Сохранить как» | Ctrl+Shift+S = «Сохранить как» (как в ТЗ), «Сохранить как проект» — без клавиши; всё переназначаемо |
| Вставка больше холста | холст увеличивается **без вопроса** | «спросить "увеличить холст?" как в оригинале» | как в оригинале — без вопроса (2 записи истории) |
| Ластик | стирает в **прозрачность**, а не цветом 2 | «стирает цветом 2» | как в оригинале — в прозрачность (видно фон); ПКМ — замена цвета 1→2 |
| Ручки холста | 8 ручек | «три ручки» | 8, как в оригинале Win11 |
| Пресеты масштаба | 10%…1000%, шаги 10/25/50 | «12.5% … 800% …» | как в оригинале |

## Найденные при сверке (заполняется на этапах 1–10)
| Область | Оригинал | PaintRS | Статус |
|---|---|---|---|
| Текстурные кисти (масло, мелок, акварель, натуральный карандаш) | собственные растровые текстуры кончика | процедурные шум/щетина с теми же тоном, шириной, сужением и накоплением (сверено замерами) | намеренно: текстуры оригинала не копируем (clean-room); выглядят похоже, но не попиксельно |
| Каллиграфия, тонкая линия вдоль пера (1–5 px) | пунктир | сплошная 1–2 px линия | мелочь, оставлено |
| Акварель | «капля» в конце штриха на старом эталоне | нет (на оригинале не воспроизвелась) | не делаем |
