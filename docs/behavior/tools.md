# Инструменты (группа Tools) — поведение оригинала

Условия: Paint 11.2605.81.0, Windows 11, 100% DPI. Тестовый холст 400×300 при масштабе 100%,
эталоны сняты захватом окна (1 пиксель экрана = 1 пиксель холста). Статусы проверки — в `../PARITY.md`.

Общая модель (важно для всех инструментов): документ = **сплошной фон** (цвет, можно скрыть) +
**прозрачные растровые слои**. Все инструменты рисуют в **активный слой**. Подробности — `layers.md`.

## Общее
- ЛКМ рисует цветом 1, ПКМ — цветом 2 (карандаш, кисти, фигуры, заливка). Проверено: карандаш, заливка.
- Горячие клавиши выбора инструментов (подсказки при наведении): Select **S**, Pencil **P**,
  Fill **B**, Text **T**, Eraser **E**, Color picker **I**, Magnifier **Z**.
- Слева над холстом — плавающие вертикальные ползунки, набор зависит от инструмента:
  | Инструмент | Ползунки |
  |---|---|
  | Карандаш, кисти | Size (размер) + Opacity (непрозрачность) |
  | Ластик | Size + кнопка ИИ-стирания (в PaintRS — нет) |
  | Заливка | Tolerance (допуск) |
  | Фигуры, выделение, текст, пипетка, лупа | нет |
- Ползунок: подсказка со значением справа от бегунка («5px», «100%», «0%»); клавиши ↑/↓ — шаг 1,
  Home/End — мин./макс.; щелчок по дорожке ставит значение; шкала размера **нелинейная**
  (≈10% хода → 11 px, 20% → 21 px, 40% → 58 px, 50% → 76 px, 70% → 128 px, 90% → 244 px; максимум 248 px).
- Минимум размера зависит от инструмента: карандаш/кисть/каллиграфия/натуральный карандаш — 1 px,
  аэрограф/масляная/пастель/маркер/акварель — 4 px; максимум у всех 248 px.
- Похоже, размер запоминается для каждого инструмента/кисти отдельно (положение бегунка менялось
  при переключении кистей) — **проверить** на этапе 3.

## Карандаш (P)
- Размер 1…248 px, по умолчанию 1 px. Непрозрачность 0…100%, по умолчанию 100%.
- 1 px: линия строго 1 px, **8-связная** (Брезенхэм, без «дыр» и без лишних угловых пикселей),
  **без сглаживания**, чистый цвет. Точки событий мыши соединяются отрезками.
  Эталон: `img/ref-pencil-1px.png`.
- Одиночный клик ставит точку.
- Размер > 1: круглый штамп, **без сглаживания** (ступенчатый круг), скруглённые концы.
- **Shift**: штрих становится прямым отрезком от точки нажатия, угол привязан к кратному 45°
  (эталон `img/ref-pencil-shift.png`: путь с изломом нарисован одной прямой под 45°).
- ПКМ — цветом 2.

## Ластик (E)
- Размер 1…248 px (шкала как у карандаша), квадратный штамп (курсор — квадратная рамка,
  отрисовывается прямо на холсте). Ползунка непрозрачности нет.
- **ЛКМ стирает в прозрачность** активного слоя (под ним виден фон; при скрытом фоне — шахматка).
  Цвет 2 не используется. Проверено: при цвете 2 = красный стёртая область прозрачная.
- **ПКМ — замена цвета**: перекрашивает в цвет 2 только пиксели, равные цвету 1, остальные не трогает
  (эталон `img/ref-eraser-rmb-replace.png`: красные участки только там, где были чёрные пиксели).
- Под ползунком — кнопка генеративного (ИИ) стирания — **не переносим**.

## Заливка (B)
- Заливает **смежную** область активного слоя цветом 1 (ПКМ — цветом 2). Связность — 4
  (диагональная 1-px линия карандаша работает как граница; проверить на этапе 2 отдельно).
- Ползунок **Tolerance 0…100%**, шаг 1%, по умолчанию **0%** (точное совпадение цвета).
  Эталон `img/ref-fill-tolerance0.png`: внутренность овала залита, граница не тронута.
- Прозрачная область слоя считается цветом «прозрачный» и заливается как обычная.
- Работает в пределах выделения, если оно есть (проверить на этапе 5).

## Пипетка (I)
- ЛКМ → цвет 1, ПКМ → цвет 2 (ПКМ проверить).
- **После одного щелчка возвращается предыдущий инструмент** (проверено: Fill → Picker → Fill).
- Берёт цвет видимого изображения или активного слоя — проверить на этапе 8.

## Лупа (Z)
- ЛКМ — приблизить, ПКМ — отдалить; шаг такой же, как у Ctrl+PageUp/PageDown (см. `view.md`).
- **Остаётся активной** после щелчка (не одноразовая).
- Масштабирование вокруг точки щелчка — проверить.

## Курсоры
Через снимки экрана курсор не виден — формы курсоров **не проверены на оригинале**.
Планируемые «смыслы» (свои рисунки): перекрёстие (карандаш/фигуры/выделение), квадратная рамка размера
(ластик, рисуется на холсте), кружок размера кисти, пипетка, ведро, лупа, I-beam (текст),
двунаправленные стрелки (ручки), «рука/перемещение» внутри выделения, «поворот» над ручкой поворота.
