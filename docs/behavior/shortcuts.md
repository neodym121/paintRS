# Горячие клавиши

Источник — подписи в меню и подсказках оригинала + проверка нажатием. «✓» — проверено нажатием,
«м» — видно в меню/подсказке, «?» — из ТЗ, не подтверждено.

## Файл
| Клавиши | Действие | |
|---|---|---|
| Ctrl+N | Новый | ✓ |
| Ctrl+O | Открыть | ✓ |
| Ctrl+S | Сохранить | м |
| Ctrl+Shift+S | **Сохранить как проект** (в оригинале!) | м |
| Ctrl+P | Печать | м |
| Ctrl+E | Свойства изображения | ✓ |

## Правка
| Ctrl+Z | Отменить | ✓ |
|---|---|---|
| Ctrl+Y | Повторить | ✓ |
| Ctrl+X / Ctrl+C / Ctrl+V | Вырезать / Копировать / Вставить | ✓ (C, V) |
| Ctrl+Shift+C | Копировать видимые слои | м |
| Ctrl+A | Выделить всё (переключает на «Выделение») | ✓ |
| Delete | Удалить выделенное (в прозрачность) | ✓ |
| Ctrl+Shift+X | Обрезать по выделению | м |
| Ctrl+Shift+I | Инвертировать цвета | м |
| Ctrl+W | Изменить размер и наклонить | ✓ |

## Вид
| Ctrl+0 | Масштаб 100% | ✓ |
|---|---|---|
| Ctrl+PageUp / Ctrl+PageDown | Приблизить / отдалить | ✓ |
| Ctrl+R | Линейки | ✓ |
| Ctrl+G | Сетка | ✓ |
| F11 | Полный экран | м |
| Ctrl+колесо / Ctrl+«+» / Ctrl+«−» | масштаб | ? |

## Инструменты (одиночные клавиши, когда фокус на холсте)
| S | Выделение | м/✓ |
|---|---|---|
| P | Карандаш | ✓ |
| B | Заливка | ✓ |
| T | Текст | ✓ |
| E | Ластик | ✓ |
| I | Пипетка | ✓ |
| Z | Лупа | ✓ |

## Слои
| Ctrl+H | Скрыть/показать слой | м |
|---|---|---|
| Ctrl+Shift+PageUp / PageDown | Слой выше / ниже | м |
| Ctrl+Shift+Delete | Удалить слой | ✓ |
| Ctrl+Shift+H | Скрыть/показать фон | м (нажатие с фокусом не на холсте не сработало) |
| Ctrl+Shift+B | Цвет фона | м |

## Текст (внутри рамки)
| Ctrl+B / Ctrl+I / Ctrl+U | Ж / К / Ч для выделенного фрагмента | ✓ (B, I) |
|---|---|---|
| Ctrl+A | выделить весь текст в рамке | ✓ |
| Esc | отменить текст | ✓ |

## Фигуры / выделение
| Enter | зафиксировать черновую фигуру | ✓ |
|---|---|---|
| Esc | снять выделение | ✓ |
| Стрелки | сдвиг выделения на 1 px | ? |
| Shift при рисовании | 45° / равные стороны | ✓ |

## Ползунки
↑/↓ — шаг 1; Home/End — минимум/максимум ✓.

## Расхождения с таблицей ТЗ
- Ctrl+Shift+S в оригинале — «Сохранить как проект»; в ТЗ — «Сохранить как».
- Ctrl++ / Ctrl+− в меню не подписаны (подписаны Ctrl+PageUp/PageDown) — в PaintRS делаем оба набора.
- В PaintRS все сочетания будут переназначаемыми через конфиг (`keymap` в `config.toml`).
