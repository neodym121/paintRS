# Раскладка окна — замеры оригинала

Условия замера: Paint 11.2605.81.0, окно развёрнуто на экране 1920×1080, масштаб Windows 100%
(96 DPI), тёмная тема, английский интерфейс. Захват — только окна Paint (PrintWindow), координаты
в физических пикселях клиентской области вместе с заголовком (окно 1920×1032 без панели задач).

Все размеры ниже — **логические пиксели** (при 100% совпадают с физическими). В PaintRS их нужно
умножать на `pixels_per_point`. Цвета приведены только как справка о контрасте/иерархии — в PaintRS
используется своя палитра (см. раздел 10 ТЗ).

Скриншоты: `img/ui-window-default.png`, `img/ui-ribbon-left.png`, `img/ui-ribbon-right.png`,
`img/ui-statusbar.png` (локальные, не публикуются — см. `img/README.md`).

### Image (74–233)
- Колонка 1 (x ≈94–111): Crop (y 80–95), Remove background (y 121–134, ИИ).
- Колонка 2 (x ≈137–169): Rotate ▾ (иконка 137–150 + шеврон 162–169, y 81–94),
  Flip ▾ (y 120–134).
- Колонка 3: Resize and skew — крупная иконка 22×22 (x 194–215, y 97–118), по центру по вертикали.
- Шаг строк — 40 px (y центров ≈ 87 и 127).

### Tools (233–370)
- Сетка 3 колонки × 2 ряда, иконки 16×16, центры: x 261 / 301 / 341, y 87 / 127 → шаг 40 px.
- Порядок: ряд 1 — Pencil, Fill, Text; ряд 2 — Eraser, Color picker, Magnifier.
- Кнопка ≈32×32, активная — с рамкой/фоном.

### Shapes (438–727)
- Галерея: рамка x 447–618, y 68–147 (≈172×80). 7 колонок, шаг ≈22 px (центры x ≈462, 484, 506, 528,
  551, 573, 595), 3 видимых ряда (центры y ≈84, 106, 128), иконки ≈14×14. Четвёртый ряд виден на ½
  снизу, прокрутка колёсиком. Вертикальный скроллбар справа (x 607–614) со стрелками ▲▼.
- Справа от галереи две строки: Outline ▾ (иконка 16 px x 632–647 + шеврон 658–665, y ≈88) и
  Fill ▾ (y ≈127). Без активной фигуры — неактивны (приглушены).
- Ещё правее — Size ▾: кнопка с превью трёх линий (x 684–707, y 93–110) + шеврон (y ≈125).

### Colors (727–1080)
- Color 1: круг 32 px (x 740–771, y 73–104) с внешним кольцом (активный слот).
- Color 2: круг 24 px (x 744–767, y 115–138). Активный слот всегда крупнее и с кольцом.
- Палитра: 10 колонок × 3 ряда, кружки 16×16, шаг 24 px; x 784…1015, y 76 / 100 / 124.
  Ряды 1–2 — предустановленные цвета, ряд 3 — пустые пользовательские (контур-окружность).
- Edit colors: «радужная» круглая кнопка 28×28 (x 1034–1061, y 94–121) с маленьким значком «+».

## Рабочая область
- Фон рабочей области (тёмная тема) — тот же тон, что строка меню (≈#202020), темнее ленты.
- Холст по центру, когда помещается; иначе — от левого/верхнего края с прокруткой.
- Рамка холста: 1 px светлее фона слева/справа, сверху ≈2 px. Тени нет.
- 8 ручек изменения размера (углы + середины сторон): квадрат 6×6, белый с тёмной рамкой 1 px,
  стоят снаружи края холста (см. `img/ui-canvas-handle-zoom.png`).
- Слева над холстом — плавающие панели ползунков (Size / Opacity или Tolerance), x ≈13–58,
  ширина ≈30 px, скругление ≈6 px, вертикально по центру рабочей области; для карандаша/кистей
  две панели (Size 168–438, Opacity 447–718 по y при развёрнутом окне).
- Справа — панель слоёв (когда открыта): ширина ≈80 px с отступами (x ≈1366–1446 в координатах
  скриншота 1456 → ≈1800–1905 физ.), холст при этом центрируется в оставшейся области.
- Текстовая панель форматирования — плавающая, по центру сверху рабочей области (y ≈190–210).

## Меню и выпадающие списки
- Выпадающие меню: ширина ≈208 px (Selection) — ≈240 px (Brushes), строка ≈32 px (обычное меню) или
  ≈46 px (меню с превью штриха), фон светлее ленты, тень, скругление ≈8 px, акцентная полоска
  слева у выбранного пункта.
- Подменю открываются справа по наведению.
- Диалоги: модальные, по центру, скругление ≈8 px, заголовок ≈20 px полужирный, нижняя полоса
  с кнопками (основная — акцентная, слева).

## Что переносим в PaintRS
Порядок и относительное положение всех зон и групп, размеры ленты/строк (с поправкой на DPI),
сетка кнопок с шагом 40/24/22 px, плавающие боковые ползунки, позиция панели слоёв и текстовой панели.
Цвета, иконки (Lucide), шрифт (IBM Plex Sans), скругления — свои.
