# Текст (T)

## Создание и редактирование
- Щелчок или протягивание по холсту создаёт **текстовую рамку**: пунктир, 8 ручек, ручка поворота
  над верхней серединой. Рамка автоматически растёт по ширине под текст и **может выходить за холст**
  (часть за холстом не видна).
- Строка состояния показывает размер рамки как размер выделения (например, «406 × 72px»).
- Текст рисуется цветом 1.
- Пока инструмент «Текст» активен, над холстом (по центру сверху рабочей области) висит **плавающая
  панель форматирования**:
  `[Шрифт ▾] [Размер ▾] | Ж · К · Ч · З | ⯇по левому · по центру · по правому⯈ | ☐ Background fill`
  Скриншот: `img/ui-text-toolbar.jpg`.
- Размеры в списке: 8, 9, 10, 11, 12, 14, 16, 18, 20, 22, 24, 26, 28, 36, 48, 72, 96, 128, 172, 256;
  поле редактируемое (можно ввести своё).
- Шрифт — системные шрифты (список), поле с поиском по вводу (проверить).
- **Форматирование применяется к выделенному фрагменту** (rich text: разные части текста могут быть
  разными); Ctrl+B / Ctrl+I / Ctrl+U работают. Ctrl+A внутри рамки выделяет весь текст.
- **Background fill**: заливает **всю рамку** цветом 2 (проверено: жёлтый прямоугольник на всю рамку).
- Параметры (шрифт, размер, флажок фона) «липкие» — сохраняются для следующей рамки.

## Фиксация и отмена
- **Esc** — отменяет текст целиком (рамка исчезает, ничего не запекается).
- **Щелчок по холсту вне рамки** — запекает текст в активный слой; новая рамка этим щелчком
  не создаётся (следующий щелчок создаст).
- Щелчок по рабочей области **вне холста** — текст пропал (один раз; повторить и уточнить на этапе 6).
- Смена инструмента — запекает (проверить).

## Не проверено (план на этап 6)
- Перенос строк, Enter, изменение размера рамки ручками, перемещение рамки.
- Поворот текстовой рамки.
- Поведение при выделении части текста мышью.
- Сглаживание текста на холсте (ClearType/градации серого).
- Шрифт по умолчанию «с нуля» (в эксперименте был выбран ранее использованный IBM Plex Sans Medium, 36).
