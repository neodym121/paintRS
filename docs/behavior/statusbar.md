# Строка состояния

Высота ≈38 px. Скрывается через View → Status bar. Скриншот: `img/ui-statusbar.png`.

## Слева (секции с вертикальными разделителями 1 px)
1. **Позиция курсора** — иконка-стрелка + «x, ypx» (координаты холста; пусто, когда курсор вне холста —
   проверить, в эксперименте значение «залипало» последним).
2. **Размер выделения** — иконка пунктирной рамки + «w × hpx» (пусто без выделения; при рисовании
   фигуры/текстовой рамки показывает их габарит).
3. **Размер изображения** — иконка рамки + «w × hpx».
4. **Размер файла** — иконка диска + «Size: 27.1KB» — только у сохранённого/открытого файла.

## Справа
- **Fit to window** (иконка «рамка с фокусом»).
- **Поле масштаба** — редактируемый combobox «100%» + шеврон со списком пресетов
  (1000…12.5%).
- **«−»**, **ползунок масштаба** (130 px, 10…1000%), **«+»**.

## Поведение
- Значения обновляются при движении мыши/рисовании.
- Масштаб показывается с одним знаком после запятой, если дробный («235.5%»).
