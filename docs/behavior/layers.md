# Слои

## Модель документа (определяет архитектуру ядра)
- **Фон (Background)** — отдельная сущность: сплошной цвет (по умолчанию белый), может быть **скрыт**
  (тогда холст показывает прозрачность шахматкой 8×8 px). Это не растровый слой.
- **Слои** — прозрачные RGBA-растры размера холста, поверх фона. Новый документ = 1 слой («Layer 1»,
  полностью прозрачный) + белый фон.
- Все инструменты рисуют в активный слой; ластик и Delete делают пиксели слоя прозрачными.
- Сохранение в плоский формат = композит (видимые слои поверх видимого фона). PNG — RGBA:
  при видимом фоне альфа = 255 везде.
- Режимов наложения и непрозрачности слоя в интерфейсе **нет** (не найдено ни в меню, ни по двойному
  щелчку). В PaintRS можно добавить прозрачность слоя как расширение (ТЗ это просит) — помечено в DIFFS.

## Панель слоёв
- Открывается кнопкой **Layers** на ленте (переключатель; кнопка подсвечена, пока панель открыта).
- Вертикальная панель у правого края рабочей области (~80 px), холст центрируется в оставшемся месте.
- Сверху — кнопка **«+»** (новый слой — над активным, становится активным; создание слоя **не**
  попадает в историю отмены — кнопка Undo осталась неактивной).
- Список миниатюр (верхний слой сверху), фон-шахматка на миниатюре, активный слой — в рамке.
- Наведение на миниатюру: подсказка с именем («Layer 2») и **значок глаза** в правом верхнем углу
  (скрыть/показать).
- Внизу панели — плитка **Background** (цвет фона). Щелчок → диалог «Background color» (тот же пикер,
  что Edit colors). Наведение — подсказка «Background» и глаз.
- Перетаскивание миниатюр для смены порядка — не проверено.

## Контекстное меню слоя (ПКМ по миниатюре)
- Hide layer — **Ctrl+H** (текст меняется на Show layer)
- Duplicate layer
- Merge down
- Move up — **Ctrl+Shift+PageUp** (неактивно у верхнего)
- Move down — **Ctrl+Shift+PageDown**
- Delete layer — **Ctrl+Shift+Delete**

## Контекстное меню фона (ПКМ по плитке Background)
- Hide background / Show background — **Ctrl+Shift+H**
- Change color — **Ctrl+Shift+B**

## Скрытый активный слой
- Над холстом появляется жёлтая информационная плашка: «активный слой скрыт — рисовать нельзя»
  с кнопкой **«Show layer»**; лента (палитра, инструменты рисования) приглушена/заблокирована.
- Скрытие слоя **попадает в историю** (Undo стал активным).

## Связь с меню
- Edit → Copy visible layers (Ctrl+Shift+C) — копирует композит видимых слоёв.
- File → Save as project (Ctrl+Shift+S) — сохраняет проект со слоями (формат `.paint`; в PaintRS —
  свой формат проекта, см. PARITY).
- Сохранение многослойного документа в PNG/JPEG/BMP/GIF → диалог «Сохранить сведённым?»
  (см. `dialogs.md`).

## Не проверено (план на этап 8)
- Порог числа слоёв; имена слоёв и переименование.
- Merge down при скрытом нижнем слое.
- Что берёт пипетка: композит или активный слой.
- Поведение заливки относительно других слоёв (по видимому изображению или по слою).
