## Меню Edit (для справки)
Cut (Ctrl+X) · Copy (Ctrl+C) · Paste (Ctrl+V, неактивно без картинки в буфере) | Copy visible layers (Ctrl+Shift+C).

## Строка меню — быстрые кнопки
Справа от меню: Save, Share, | Undo, Redo (неактивны, когда нечего отменять/повторять).
Справа в строке: Feedback (не переносим), Settings (шестерёнка → страница настроек).

## Новый документ
- Размер нового холста = **последний размер холста** в сессии/между запусками (видели 2304×1296 при
  первом запуске, затем 400×300 и 1200×900 — даже если увеличение было отменено).
- Кнопка Default в свойствах изображения → 1152×648 (= 0,6 × разрешения экрана 1920×1080).
- Цвета 1/2 сбрасываются в чёрный/белый.
- Инструмент при старте приложения — Brush.

## Сохранение
- Диалог «Сохранить как»: имя по умолчанию `Untitled.png` (или `.jpg` для JPEG), тип выбирается.
- Неверное имя → системное сообщение «имя файла недопустимо».
- PNG: RGBA 8 бит, sRGB + gAMA, pHYs 96 DPI. При видимом фоне альфа везде 255.
- JPEG: **без диалога качества**; качество ≈94 (по таблицам квантования IJG), субдискретизация 4:2:0,
  JFIF, 96 DPI.
- Многослойный документ в плоский формат → диалог **«Save as flattened image?»**
  (смысл: «слои нельзя будет редактировать в сохранённом файле; сохраните проект, чтобы
  редактировать позже»). Кнопки: **Save as project file** (основная) · **Continue** · **Cancel**.
  Показывается **после** выбора имени файла. После «Continue» слои в редакторе остаются.
- После сохранения: заголовок окна «имя.расширение - Paint», в строке состояния появляется
  «Size: 27.1KB» (размер файла на диске).
- **Заголовок не меняется при несохранённых изменениях** (звёздочки нет).

## Вопрос о несохранённых изменениях
- Заголовок «Do you want to save your work?» (смысл: «сохранить работу?»), текст: есть несохранённые
  изменения в «Untitled» / в «полный\путь\к\файлу».
- Кнопки: **Save** (основная, по умолчанию) · **Don't save** · **Cancel**.
- Save у безымянного → диалог «Сохранить как» → после сохранения действие (New) продолжается.

## Не проверено
- BMP (24/32 бит?), GIF (палитра, дизеринг), TIFF/ICO/WebP через «Other format».
- Предупреждение о потере прозрачности при сохранении в JPEG/BMP с скрытым фоном.
- Drag-and-drop файла в окно, открытие из командной строки.
- Вставка в пустой документ (Ctrl+V) — заменяет ли холст.
- Print preview / Page setup.
