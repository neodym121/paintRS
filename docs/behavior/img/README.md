# Изображения

- `ref-*.png` — эталонные результаты на холсте: наши тестовые штрихи/фигуры, нарисованные в оригинале
  (400×300, 100%, захват 1:1). Используются для сравнения на этапах приёмки. Публикуются в репозитории.
- `ui-*` — снимки интерфейса оригинала (с его иконками и оформлением) для сверки раскладки.
  Это ассеты Microsoft, поэтому они **не коммитятся** (см. `.gitignore`) и лежат только локально.
  Если нужно — их можно пересоздать по описаниям в `../layout.md`.
