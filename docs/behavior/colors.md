# Цвета (группа Colors)

## Слоты
- **Color 1** (основной) и **Color 2** (вторичный). По умолчанию чёрный / белый.
- Щелчок по слоту делает его **активным**: активный круг крупнее (32 px) и с кольцом, неактивный — 24 px.
- **Ctrl+N (новый документ) сбрасывает цвета** к чёрному/белому (наблюдалось после «Не сохранять»).

## Палитра
- 10 × 3 кружков. Ряды 1–2 — предустановленные цвета, ряд 3 — пустые слоты пользовательских цветов.
- Состав по смыслу (слева направо): ряд 1 — чёрный, серый, тёмно-красный, красный, оранжевый, жёлтый,
  зелёный, голубой/бирюзовый, синий-индиго, фиолетовый; ряд 2 — белый, светло-серый, коричневый,
  розовый, золотой, светло-жёлтый, лайм, светло-бирюзовый, серо-голубой, лавандовый.
  **В PaintRS — своя палитра** с той же логикой (тёмные/насыщенные сверху, светлые снизу),
  без копирования значений.
- Наведение — подсказка с названием цвета («Red», «Green»).
- **ЛКМ по кружку → активный слот; ПКМ → неактивный слот** (проверено в обе стороны).
- Пользовательские цвета (ряд 3) не сохраняются между запусками.

## Edit colors (кнопка-«радуга»)
Диалог (см. `dialogs.md`, `img/ui-dialog-edit-colors.png`):
- Слева — спектр: по горизонтали тон, по вертикали насыщенность (внизу белый); кружок-маркер.
- Превью выбранного цвета (вертикальная плашка).
- Вертикальный ползунок яркости (значения) — справа от превью.
- Поле HEX (`#3366CC`), выпадающий список **RGB / HSV**, три числовых поля (Red/Green/Blue или H/S/V).
- Basic colors — 12 × 4 = 48 цветов; Custom colors — 6 × 4 = 24 слота + кнопка «+» (добавить).
- OK / Cancel. **OK → цвет уходит в активный слот и добавляется в первый пустой кружок ряда 3 палитры**.
  Повторный OK с цветом, который уже есть в ряду 3, **не добавляет дубль**. Когда ряд заполнен (10), новый цвет
  встаёт в конец, самый старый уходит (сдвиг влево). Проверено 16.10.2026.
- **«+» в Custom colors** добавляет текущий цвет диалога в первый свободный слот; следующий слот отмечен кольцом.
- Тот же диалог используется для «Background color» слоя фона (заголовок другой).

## Не проверено
- Альфа-канал цвета (в UI нет поля прозрачности).
- Двойной щелчок по кружку палитры.
