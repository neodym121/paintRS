# Выделение (группа Selection)

## Кнопка и меню
Большая кнопка (инструмент выделения, **S**) + шеврон → меню:
- Rectangle (прямоугольное) — отмечено как текущее
- Free-form (произвольное, лассо)
- —
- Select all (Ctrl+A)
- Invert selection (неактивно без выделения)
- Transparent selection (переключатель)
- —
- Delete (Delete) (неактивно без выделения)

Скриншот меню: `img/ui-menu-selection.png`.

## Поведение
- **Ctrl+A** включает инструмент выделения и выделяет весь холст.
- Рамка выделения — чёрно-белый пунктир; **8 ручек** (квадратики) по углам и серединам сторон;
  **ручка поворота** — кружок со стрелкой над верхней серединой (≈22 px выше рамки) — свободный поворот.
- Под выделением всплывает плавающая панель с ИИ-кнопками (генеративное стирание, удаление фона) —
  **не переносим**.
- Строка состояния показывает размер выделения «w × hpx».
- **Перетаскивание** изнутри — перемещение. Освободившееся место становится **прозрачным** (на слое;
  при видимом фоне выглядит белым), а не цветом 2. Эталон `img/ui-selection-move.png`.
- После фиксации перемещённый фрагмент **накладывается поверх** с альфой (прозрачные пиксели
  фрагмента не затирают то, что под ними).
- **Delete** — очищает выделенное в прозрачность (проверено при цвете 2 = красный: результат не красный).
- Фиксация — щелчок вне выделения / смена инструмента; Esc — снять выделение.
- Вставка (Ctrl+V) создаёт плавающее выделение в левом верхнем углу; если картинка **больше холста —
  холст автоматически увеличивается без вопроса** (две записи истории: «расширение холста» и «вставка»).

## Не проверено (план на этап 5)
- Ctrl+перетаскивание (копия), Shift+перетаскивание («шлейф»).
- Стрелки — сдвиг на 1 px.
- Transparent selection: какие пиксели становятся прозрачными (классика — цвет 2).
- Free-form: форма, замыкание, рамка-габарит.
- Поворот/отражение/изменение размера выделения через меню и ручки.
- Crop по выделению, Invert selection.
- Курсоры над ручками.
