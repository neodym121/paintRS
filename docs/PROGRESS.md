## Принятые решения (подтверждены автором 16.10.2026)
- Фигуры — **без сглаживания** по умолчанию (как в оригинале) + переключатель «Сглаживать фигуры» в настройках.
- Ластик ЛКМ стирает **в прозрачность**; ПКМ — замена цвета 1 → цвет 2.
- Вставка картинки больше холста — холст растёт **без вопроса** (2 записи истории).
- Ctrl+Shift+S = «Сохранить как» (по ТЗ); «Сохранить как проект» — без клавиши; все клавиши переназначаемые.
- 8 ручек холста; масштаб 10–1000%, шаги 10/25/50%.
- Модель документа: фон (цвет + видимость) + прозрачные RGBA-слои (premultiplied).
- Формат проекта — свой `.paintrs` (zip: manifest.json + PNG слоёв).
- Скриншоты интерфейса оригинала (`docs/behavior/img/ui-*`) — только локально, в .gitignore.
- Репозиторий: отдельный git в `Media/paintRS`, remote `origin` = github.com/neodym121/paintRS. **Не пушить без просьбы.**
- Коммит после каждого этапа (так просит ТЗ). Ответы автору — по-русски, на «ты».

- **Оригинал — только современный Paint из Microsoft Store** (Computer use: `open_application "Paint"`).
  Команда `mspaint` на этой LTSC-сборке запускает классический Paint из Windows 7–10 — не использовать.
  Окно оригинала искать как `class:MSPaintApp` (подстрока «Paint» находит и PaintRS).
- Помощники для исследования оригинала (во временной папке сессии, при потере — переписать):
  захват окна Paint через PrintWindow, протяжки мышью через SendInput; Shift/Ctrl при протяжке —
  держать через Computer use `hold_key` параллельно с фоновой протяжкой (эмулированный модификатор Paint не видит).

## Этап 1 — подробности

- paint-core (29 тестов): geom (IRect), color (Rgba straight / Px premultiplied, mul_div255), raster,
  document (фон + слои с LayerId, composite_into, flatten, resize_canvas, add_layer, state/restore),
  history (PixelRecorder — тайлы 64×64 до/после; DocState-снимки; лимит 100 + бюджет памяти; state_id для «изменён»),
  zoom (шаги 10/25/50, пресеты, fit, label/parse), io (decode любых форматов через image, PNG с sRGB+96 DPI).
- Шрифты в `crates/paint-ui/assets/fonts/`: IBM Plex Sans Regular/Medium/SemiBold (урезаны `tools/fonts/subset_plex.py`),
  Lucide (урезан до 128 иконок `tools/icons/build_icons.py` + `tools/icons/icons.txt`; генерирует `paint-ui/src/icons.rs`).
  Для перегенерации нужен fontTools и распакованный npm-пакет lucide-static.
- Решение по холсту: egui-wgpu не умеет мипмапы → свой wgpu-пайплайн через `egui_wgpu::Callback`:
  мипы считаются на CPU (box 2×2, premultiplied), загрузка только грязных прямоугольников, UV из @builtin(position),
  шахматка и сетка пикселей в шейдере.

- paint-ui: тема (`theme.rs`, свои палитры, радиус 4), шрифты (`fonts.rs`), RU/EN (`i18n.rs`, struct Tr),
  `actions.rs` (Action + Keymap: умолчания из shortcuts.md, переопределение через `[keymap]` в config.toml),
  `editor.rs` (Editor: документ, история, вид, инструмент, цвета, поток «сохранить изменения?», файлы через rfd),
  `menubar.rs`, `ribbon.rs` (геометрия из layout.md; инструменты/кисти/фигуры/палитра выбираются, действия — по этапам),

- paint-app: main (eframe + wgpu, лимит текстуры = максимум адаптера; только dx12 на Windows), config.rs (TOML в

## Известные проблемы / заметки
- Ctrl+колесо через Computer use не масштабирует (инструмент не держит Ctrl во время колеса); настоящий Ctrl+колесо
  (SendInput) работает. Для проверок — `wheel.ps1` во временной папке или клавиши Ctrl+PgUp/PgDn.
- Не делать `cd` в подпапки в Bash: рабочая папка сессии «прилипает».
- Холст больше лимита GPU показывается с уменьшенного мип-уровня (CanvasGpu::recreate, base_level).
- Иконка окна пока стандартная egui (своя — этап 10).
- Замеры этапа 1 (release, RX 7600, DX12): exe 9.3 МБ; первый кадр ≈0.3–0.4 с (≈200 мс — создание wgpu/DX12:
  instance → адаптеры → device); рабочий набор ≈135 МБ, из них большая часть — драйвер DX12. Цели ТЗ (<300 мс, 30–60 МБ)
  пока не достигнуты → этап 10: попробовать только DX12 в маске backends, LowPower, отложенную инициализацию, Vulkan/GL.

## Этап 3 — подробности (готов 16.10.2026)
- paint-core `brush.rs`: BrushStroke строит маску покрытия (тайлы 64×64: base + run + when), слой = оригинал ⊕ цвет ×
  маска × непрозрачность (оригинальные пиксели — из PixelRecorder, `original_tile`). Внутри одного прохода — максимум;
  повторный проход (пиксель не трогали дольше размера кисти по длине штриха) — накопление (масло, мелок, маркер,
  натуральный карандаш). Формы: круг AA (Brush), перо 45° по 4-связному пути (каллиграфия), точки в круге (аэрограф:
  20 при нажатии, 2,5/px пути, 300/с по таймеру), полоса с плоскими концами + перекрытие стыков (остальные).
  `finish()` — мягкий конец масла/акварели.
- paint-ui: штрих кисти в `tools.rs` (StrokeTool::Brush, тик аэрографа с request_repaint), события мыши обрабатываются
  **по порядку** (отпускание и новое нажатие в одном кадре = два штриха), курсоры кистей, меню кистей со строками 44 px
  и образцами штрихов (рисуются тем же движком), ползунок у кистей с минимумом 4 px начинается с 4.
- Сверка: `tools/compare/brush_study.py` (одинаковый сценарий для обоих окон, холст 1500×720 в развёрнутом окне,
  начало холста (210, 201) в обоих) + `cmp_row.py`. Brush 0,57; Marker 2,5; Natural pencil 4,7 (тон совпадает);
  каллиграфия 3–5; аэрограф/масло/мелок/акварель — похожи по тону и форме, текстуры свои (DIFFS).
